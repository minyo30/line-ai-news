# 業界の兆し＆AI活用事例をLINEに1日3回送るツール

国内外9サイトの新着から記事を選び、日本時間 8:00 / 12:00 / 19:00 ごろにLINEへ送ります。
（GitHubの混雑で数分〜数十分遅れることがあります）

## 届く内容
- **① 伸びている業界** … 資金調達・過去最高・新業態・ライバーなど「勢い」を示す言葉を含む記事。提案先さがし用
- **② AI活用事例・動向** … AI・導入事例・FDEなどを含む記事。自社で取り入れるネタ用
- 記事の頭の【】は、どの言葉に反応したかを表します
- AIの言葉を含む記事は②に入ります（例：「AIスタートアップが資金調達」は②）

## ファイルの役割
- `keywords_industry.txt` … ①用のキーワード（自由に追加・削除できます）
- `keywords_ai.txt` … ②用のキーワード
- `feeds.txt` … 読み込むサイトと送り方（全件／キーワードで絞る／兆し検知だけ）
- `stopwords.txt` … 兆しとして通知しない言葉
- `main.py`・`trends.py` … 本体（触らなくてOK）
- `sent.json`・`terms.json` … 送信済み記事と言葉の記録（自動更新）

## 兆しレポート（毎週月曜の朝）
Googleトレンドを含む全サイトの記事から、カタカナ語（例: ライバー）・英語の略語（例: FDE）・英語の複合語（例: Forward Deployed Engineer）・「」で囲まれた言葉（例: 「推し活タクシー」）を拾って記録します。
- **新しく出てきた言葉**：これまで出てこなかった言葉が、直近7日で3回以上・2サイト以上に出たもの
- **急に増えた言葉**：以前の週平均の3倍以上に増えたもの

最初の2週間は「普段よく出る言葉」を覚える準備期間なので、兆しレポートは3週目の月曜から届きます。
通知の条件は `trends.py` 冒頭の数字（MIN_COUNT など）で調整できます。

## セットアップ（パソコンでの作業がおすすめ・所要30分ほど）

### 1. LINE側の準備
1. LINE公式アカウントを作成（https://entry.line.biz/ 、無料のコミュニケーションプランでOK）
2. 公式アカウント管理画面 →「設定」→「Messaging API」→「Messaging APIを利用する」
3. LINE Developers（https://developers.line.biz/console/）で作成されたチャネルを開く
   - 「Messaging API設定」タブの一番下で **チャネルアクセストークン（長期）** を発行してコピー
   - 「チャネル基本設定」タブの **あなたのユーザーID**（Uから始まる文字列）をコピー
4. 「Messaging API設定」タブのQRコードを自分のLINEで読み取り、友だち追加する

### 2. GitHub側の準備
1. GitHubで新しいリポジトリを作成（Privateで大丈夫です）
2. 「Add file」→「Upload files」で、このフォルダの中身をすべてアップロード
   - `.github` フォルダが隠れて見えない場合は「Add file」→「Create new file」で
     ファイル名に `.github/workflows/news.yml` と入力し、中身を貼り付けてください
3. 「Settings」→「Secrets and variables」→「Actions」→「New repository secret」で2つ登録
   - 名前 `LINE_CHANNEL_ACCESS_TOKEN` … 1-3でコピーしたトークン
   - 名前 `LINE_USER_ID` … 1-3でコピーしたユーザーID

### 3. 動作テスト
「Actions」タブ →「AIニュースをLINEに送る」→「Run workflow」を押す。
1〜2分でLINEに届けば完了です。以降は自動で1日3回動きます。

## うまくいかないとき
- Actionsの実行ログに「取得失敗: ○○」と出たら、そのサイトのRSSのURLが変わっている可能性があります。
  サイトでRSSのURLを確認して `feeds.txt` を書き換えてください。
- 「LINE送信エラー 401」はトークンの貼り間違い、「400」はユーザーIDの貼り間違いが多いです。
